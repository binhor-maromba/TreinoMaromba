# Treino da Gislaine

Aplicativo web instalável para treinos de terça a sexta, com cardio guiado de baixo esforço nos dias de superiores e inferiores.

- No iPhone, abra a página do GitHub Pages no Safari e use **Compartilhar → Adicionar à Tela de Início**.
- No Android, use **Instalar app** ou **Adicionar à tela inicial**.
- Os registros ficam neste navegador. Exporte um backup antes de trocar de aparelho ou limpar os dados.

Inclui séries, cargas e repetições, vídeos de execução, cardio por etapas com temporizador, histórico, backup e cronômetro de descanso.
