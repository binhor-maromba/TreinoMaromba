# Treino da Gislaine

Aplicativo web instalável para acompanhar o plano semanal de terça a sexta.

- Abra a página publicada no GitHub Pages.
- No iPhone, abra no Safari e use **Compartilhar → Adicionar à Tela de Início**.
- No Android, use a opção **Instalar app** ou **Adicionar à tela inicial** do navegador.
- Os registros ficam neste navegador. Use **Exportar backup JSON** antes de trocar de aparelho ou limpar os dados.

Inclui treinos semanais, vídeos de execução no YouTube, registro de séries, cargas e repetições, cardio, histórico e cronômetro de descanso.
