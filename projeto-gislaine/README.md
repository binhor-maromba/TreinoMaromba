# Treino da Gislaine

Aplicativo web instalável para acompanhar o plano semanal de terça a sexta.

- Abra `index.html` pela página publicada do GitHub Pages.
- No iPhone, abra no Safari e use **Compartilhar → Adicionar à Tela de Início**.
- No Android, use a opção **Instalar app** ou **Adicionar à tela inicial** do navegador.
- Os registros e o histórico ficam neste navegador. Use **Exportar backup JSON** antes de trocar de aparelho ou limpar os dados.

O app inclui treino semanal, registro de cargas e repetições, histórico, cronômetro de descanso e exportação/importação de backup.
